# L: Môi trường thi và chiến thuật

## Hình thức
- 2 giờ, online có giám thị qua webcam (PSI), khoảng 15–17 câu thực hành, đỗ từ **66%**. Một lần thi lại miễn phí.
- Bạn làm trong một **máy ảo Linux từ xa** (remote desktop) có terminal và trình duyệt. Được mở tab tới: kubernetes.io/docs, kubernetes.io/blog, helm.sh/docs, gateway-api.sigs.k8s.io (kiểm tra danh sách chính thức trước khi thi).
- Mỗi câu có trọng số riêng (khoảng 4–8%), ghi rõ cluster/context, và thường có **điểm thành phần** — làm được một phần vẫn có điểm.
- Mua đề có kèm 2 lượt **killer.sh** (mỗi lượt mở 36 giờ), khó hơn đề thật.

## Chiến thuật thời gian
1. Đọc lướt toàn đề (2–3 phút), làm câu dễ / điểm cao trước.
2. Câu nào quá ~7 phút → **flag**, làm tiếp, quay lại sau.
3. **Luôn chạy lệnh đổi context** được cho ở đầu câu (copy nguyên văn).
4. Câu SSH vào node: làm xong `exit` về máy gốc.
5. Sau mỗi câu, xác minh nhanh (`get`, `describe`, `auth can-i`, `curl`).
6. Dành 10 phút cuối rà các câu đã flag.

## Thói quen gõ nhanh
- `k` + `$do` cho mọi object tạo được bằng lệnh, chỉ dùng YAML khi bắt buộc.
- Docs: tìm từ khoá (ví dụ "NetworkPolicy", "PersistentVolume", "HTTPRoute") và copy YAML mẫu.
- Copy/paste trong terminal của máy thi: `Ctrl+Shift+C` / `Ctrl+Shift+V`.
- Đừng tốn thời gian làm đẹp YAML; miễn đúng.

:::ex
Liệt kê 6 trang docs bạn sẽ mở nhiều nhất trong phòng thi, và từ khoá để tìm nhanh từng trang. Thử tìm và copy YAML mẫu của mỗi trang trong dưới 30 giây.
:::sol
Gợi ý: "Network Policies", "Configure a Pod to Use a PersistentVolume for Storage", "Operating etcd clusters" (backup/restore), "Upgrading kubeadm clusters", "Ingress", "HTTPRoute" (gateway-api), "Assign Pods to Nodes using Node Affinity", "Taints and Tolerations", "Using RBAC Authorization", "kubectl Quick Reference".
:::end

:::ex
Làm lab dọn sạch môi trường: chạy đúng 3 dòng chuẩn bị (alias/biến/vimrc) trong vòng 30 giây mà không nhìn tài liệu.
:::sol
```bash
alias k=kubectl ; export do="--dry-run=client -o yaml" ; export now="--force --grace-period=0"
echo 'set et ts=2 sw=2 nu' >> ~/.vimrc
```
:::end

# L: Speed drill – 20 việc dưới 2 phút

Bấm giờ từng việc. Mục tiêu: mỗi việc ≤ 2 phút, tổng < 35 phút. Lặp lại 3 lần trong tuần.

:::ex
Đợt 1 (Workloads & Networking):
1. Deployment `d1` nginx:1.27, 3 replica, label tier=web.
2. Đổi image `d1` sang 1.28, rồi rollback.
3. Expose `d1` NodePort port 80.
4. Pod `p1` busybox `sleep 3600` có requests cpu 100m memory 64Mi.
5. ConfigMap `c1` (A=1) và pod dùng `envFrom`.
6. NetworkPolicy deny-all ingress ở namespace `drill`.
7. Ingress `i1` host d.local → svc d1:80.
8. Job `j1` busybox `echo ok`, completions 3.
9. CronJob `cj1` mỗi 10 phút.
10. HPA cho `d1` CPU 60%, 1–5.
:::sol
```bash
k create deploy d1 --image=nginx:1.27 --replicas=3 $do > d1.yaml
# vim: thêm "tier: web" vào template.metadata.labels (và metadata.labels), rồi k apply -f d1.yaml
k set image deploy/d1 nginx=nginx:1.28 ; k rollout undo deploy/d1
k expose deploy d1 --type=NodePort --port=80
k run p1 --image=busybox $do -- sleep 3600 > p1.yaml   # thêm resources, apply
k create cm c1 --from-literal=A=1                       # pod: envFrom configMapRef c1
k create ns drill ; printf 'apiVersion: networking.k8s.io/v1\nkind: NetworkPolicy\nmetadata: {name: deny, namespace: drill}\nspec: {podSelector: {}, policyTypes: [Ingress]}\n' | k apply -f -
k create ingress i1 --rule="d.local/*=d1:80"
k create job j1 --image=busybox $do -- echo ok > j1.yaml   # thêm completions: 3
k create cronjob cj1 --image=busybox --schedule="*/10 * * * *" -- date
k autoscale deploy d1 --cpu-percent=60 --min=1 --max=5
```
:::end

:::ex
Đợt 2 (Cluster & Storage & Troubleshooting):
11. SA `s1` + Role chỉ get/list secrets ở ns `drill` + binding.
12. ClusterRole xem nodes cho user `u1`.
13. Backup etcd ra `/opt/d.db`.
14. PV 1Gi hostPath + PVC 500Mi bind với nhau.
15. StorageClass mặc định mới.
16. Taint node01 `x=y:NoSchedule` và pod có toleration.
17. Drain rồi uncordon node01.
18. Ghi pod restart nhiều nhất (mọi ns) vào file.
19. Ghi tên mọi image đang chạy trong `kube-system` (không trùng) vào file.
20. In lệnh join.
:::sol
```bash
k create sa s1 -n drill ; k create role r1 -n drill --verb=get,list --resource=secrets
k create rolebinding rb1 -n drill --role=r1 --serviceaccount=drill:s1
k create clusterrole nr --verb=get,list,watch --resource=nodes ; k create clusterrolebinding nrb --clusterrole=nr --user=u1
ETCDCTL_API=3 etcdctl --endpoints=https://127.0.0.1:2379 --cacert=/etc/kubernetes/pki/etcd/ca.crt --cert=/etc/kubernetes/pki/etcd/server.crt --key=/etc/kubernetes/pki/etcd/server.key snapshot save /opt/d.db
# 14, 15: copy YAML từ docs (bài Storage)
k taint node node01 x=y:NoSchedule   # pod: tolerations [{key: x, operator: Equal, value: y, effect: NoSchedule}]
k drain node01 --ignore-daemonsets --delete-emptydir-data ; k uncordon node01
k get po -A --sort-by=.status.containerStatuses[0].restartCount --no-headers | tail -1 > /root/most-restart.txt
k get po -n kube-system -o jsonpath='{.items[*].spec.containers[*].image}' | tr ' ' '\n' | sort -u > /root/images.txt
kubeadm token create --print-join-command
```
:::end

# L: Ôn tập cuối và checklist ngày thi

## Tự kiểm tra – phải làm được không cần docs
- ☐ etcd backup/restore (nhớ 4 cờ, đổi hostPath)
- ☐ Upgrade control plane + worker bằng kubeadm
- ☐ Role/ClusterRole/Binding + `auth can-i`
- ☐ NetworkPolicy ingress + egress, phân biệt AND/OR
- ☐ Service các loại, debug endpoint rỗng
- ☐ PV/PVC/SC, SC mặc định
- ☐ Sửa kubelet NotReady, sửa static pod control plane
- ☐ Helm install/upgrade với `--set`, Kustomize `apply -k`
- ☐ HPA, sidecar native, taint/toleration, affinity
- ☐ jsonpath, sort-by, ghi kết quả ra file đúng định dạng

## Phải làm được với docs trong ≤ 5 phút
- ☐ Gateway + HTTPRoute (chuyển từ Ingress)
- ☐ Cài CNI từ manifest/Helm
- ☐ CRD: liệt kê, explain trường
- ☐ Cài cri-dockerd + sysctl
- ☐ CSR tạo user

## Trước ngày thi
- Chạy **system check** của PSI trên đúng máy sẽ thi; chỉ 1 màn hình; tắt phần mềm nền.
- Giấy tờ tuỳ thân có ảnh, tên khớp với tài khoản Linux Foundation (thường là hộ chiếu với người Việt).
- Phòng riêng, bàn trống, không ai vào, có đèn đủ sáng. Đăng nhập sớm 30 phút.
- Ngủ đủ, không học nội dung mới trong ngày cuối.

:::ex
Làm lại toàn bộ tab **Thi thử** 2 lần trong tuần này. Ghi lại các câu sai vào một danh sách, mỗi câu sai làm lại 3 lần vào các ngày khác nhau.
:::sol
Mục tiêu: ≥ 80% ở lần thi thử thứ 2, và ≥ 70% ở killer.sh lượt 2 (đề killer.sh khó hơn đề thật).
:::end
