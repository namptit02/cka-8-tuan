Có cần học Linux và Docker không?

Linux: CÓ, bắt buộc. Cả bài thi chạy trên terminal Ubuntu. Nhiều câu yêu cầu SSH vào node, sửa file YAML bằng vim, xem log kubelet bằng journalctl, khởi động lại service bằng systemctl. Yếu Linux là mất điểm phần Troubleshooting (30%).

Docker: CHỈ CẦN KHÁI NIỆM, 1–2 ngày. K8s dùng containerd chứ không dùng Docker nữa, đề không bắt viết Dockerfile. Bạn cần hiểu image, container, registry, tag và biết dùng crictl để xem container trên node. Đề mới có thể bắt cài cri-dockerd từ file .deb, nhưng đó là thao tác Linux (dpkg, systemctl), không phải kiến thức Docker sâu.

Linux – tối thiểu phải thành thạo

Vim (quan trọng nhất)
  • i chèn · Esc thoát · :wq lưu thoát · :q! bỏ
  • dd xoá dòng · yy copy · p dán · u undo
  • /từ tìm · n tiếp · :set nu số dòng
  • Thụt lề nhiều dòng: Shift+V chọn → > hoặc <
  • Cài sẵn ~/.vimrc: set ts=2 sw=2 et để YAML không lỗi tab
systemd & log
  • systemctl status|start|restart|enable kubelet
  • systemctl daemon-reload sau khi sửa unit file
  • journalctl -u kubelet -f · --no-pager | tail -50
  • Log container trên node: /var/log/pods/, /var/log/containers/
File, quyền, tìm kiếm
  • ls -la, cat, less, head, tail
  • chmod, chown, sudo -i
  • grep -rn, find / -name, awk '{print $1}'
  • Pipe & redirect: |, >, >>, 2>&1
  • base64 -d (giải mã Secret)
Mạng
  • ip a, ip route, ss -tlnp (port đang nghe)
  • curl -v, nslookup/dig, ping, nc -zv host port
  • sysctl, file /etc/sysctl.d/*.conf, sysctl --system
  • Hiểu IP, subnet/CIDR, DNS, port, iptables ở mức khái niệm
Gói phần mềm (cho upgrade cluster)
  • apt-get update, apt-cache madison kubeadm
  • apt-mark hold|unhold, apt-get install pkg=version
  • dpkg -i file.deb
File K8s trên node cần nhớ
  • /etc/kubernetes/manifests/ – static pod control plane
  • /etc/kubernetes/pki/ – chứng chỉ (cả etcd)
  • /var/lib/kubelet/config.yaml – cấu hình kubelet
  • /etc/kubernetes/kubelet.conf, admin.conf
  • /etc/cni/net.d/ – cấu hình CNI

Container / Docker – chỉ cần thế này

Khái niệm
  • Image (template, nhiều layer) vs container (process đang chạy từ image)
  • Registry, tag: nginx:1.27, registry.io/app:v2
  • Namespace & cgroup của Linux là nền tảng cách ly / giới hạn CPU-RAM
  • CRI: kubelet nói chuyện với containerd/CRI-O qua socket, Docker cần cri-dockerd
  • Port mapping, biến môi trường, volume mount
crictl (dùng trên node khi debug) 
crictl ps -a            # container, kể cả đã chết
crictl pods
crictl logs <id>
crictl images
crictl inspect <id>

Dùng khi kube-apiserver chết và kubectl không chạy.

Mẹo làm bài
  • Được mở kubernetes.io/docs, /blog, helm.sh/docs, gateway-api.sigs.k8s.io trong bài thi. Tập tìm YAML mẫu nhanh trên docs.
  • Câu nào quá 7–8 phút thì flag rồi bỏ qua, quay lại sau. ~15–17 câu trong 120 phút.
  • Copy/paste trong terminal thi: Ctrl+Shift+C / Ctrl+Shift+V.
  • Câu bắt SSH vào node: nhớ exit về máy chính trước khi sang câu tiếp.
  • Câu bắt ghi kết quả ra file: kiểm tra lại đúng đường dẫn, đúng định dạng.
  • Có quyền 2 lượt killer.sh khi mua đề, khó hơn đề thật. Dùng ở tuần 7 và tuần 8.

Khung báo lỗi / trống? Bấm ↗ để mở terminal trong tab riêng: nếu tab đó cũng không vào được thì ttyd trên VM chưa chạy (xem bước 2); nếu tab đó chạy được thì bấm biểu tượng ổ khoá/cài đặt cạnh thanh địa chỉ của trang này → Site settings → bật Local network access (Truy cập mạng cục bộ), rồi bấm Kết nối lại.

  1. SSH vào VM: ssh namhv25@192.168.64.5
  2. Chạy script cài web terminal (ttyd) trong repo:
    curl -fsSL https://raw.githubusercontent.com/namptit02/cka-8-tuan/main/scripts/setup-web-terminal.sh | bash
    (Repo private thì copy file scripts/setup-web-terminal.sh sang VM rồi chạy bash setup-web-terminal.sh.)
  3. Mở địa chỉ terminal trong tab mới một lần, chọn “Nâng cao → Tiếp tục” để chấp nhận chứng chỉ tự ký, rồi quay lại đây.
  4. Bấm Kết nối. Nếu Chrome hỏi quyền truy cập thiết bị trong mạng cục bộ, chọn Cho phép.

Mẹo: mỗi khối lệnh trên trang có nút Copy, dán vào terminal bằng Ctrl+Shift+V (Mac: ⌘V). Màn rộng: terminal nằm bên phải, kéo mép trái để đổi độ rộng. Bấm ✕ chỉ ẩn khung, phiên không mất.

Terminal chỉ chạy được khi máy bạn đang thấy VM (cùng máy Mac / cùng mạng). Bản xem trên claude.ai không cho nhúng terminal; dùng bản Vercel.
